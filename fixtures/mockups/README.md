# Mockupbestandenset

Hier staan **20 echte, maar volledig fictieve bestanden**, verdeeld over de juiste formaatmappen. De naam begint steeds met `EAIhome_mockup_`.

Voorbeeld: `docx/EAIhome_mockup_doc.docx`, `xlsx/EAIhome_mockup_xlsx.xlsx`, `pptx/EAIhome_mockup_pptx.pptx`.

De volledige formatmatrix staat in [docs/MOCKUPS.md](../../docs/MOCKUPS.md). `manifest.json` bevat hashes en verwachte testuitkomsten. Een ondersteund formaat is iets anders dan een bestand dat EAIhome daadwerkelijk kan uitlezen: momenteel kan de importer alleen UTF-8 tekst, Markdown, CSV, JSON en de tekst uit EML verwerken.

Alle gegevens in deze map zijn verzonnen.
